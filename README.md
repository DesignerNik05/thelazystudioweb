# The Lazy Studio — previous site design

The site that ran at thelazystudio.com until 5 October 2026, kept for reference. The live site is
now the new one, built in `~/Downloads/The Lazy Studio/Website` (repo akashkalsi9/thelazystudiosite)
and hosted on Cloudflare.

Its last deployed build still sits on GoDaddy as the fallback. To bring it back, delete the
`thelazystudio.com/*` route in Cloudflare (thelazystudio.com → Workers Routes).

To look at it locally: `npm install`, then `npm run dev`.
